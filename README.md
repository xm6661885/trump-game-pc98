# 中期选举夜骑 · Midterm Night Ride

粉色像素风跑酷小游戏。在线玩：https://xm6661885.github.io/trump-game-pc98/

## 玩法
- 空格 / ↑ / 点屏幕：跳；↓ / 下滑 / 「趴」：压低；P 暂停
- 选票收集、擦边连击（倍率最高 ×5）
- 道具：能量饮料（无敌）、护盾、沙漏（慢动作）、磁铁
- 每跑一段完成一个州，切换场景（投票站 / 街区 / 大桥 / 黎明）+ 计票冲刺（踩拍子、选票双倍）
- 新障碍：泥水坑、弹跳脑袋、先跳后趴组合；随机事件：雨夜、顺/逆风、操作反转
- 新面孔：卢比奥（快速滚来）、哈梅内伊（高个，要跳满）、拜登（趴地打盹、靠近突然起身）、泽连斯基（双连飞，一直趴）、希拉里（从天上俯冲）
- 难度：休闲（几乎不加速）/ 标准 / 地狱（起步快、加速猛、新花样早出）；今日挑战（按日期定种子，所有人同一张图）
- 翻车动画：像素爆炸 + 翻车 + 震屏，主菜单像素扫描式展开
- 车库：车手和车皮肤按成绩解锁；标准/地狱单局 300 分并跑到第 4 州后，可上传自己的照片当车手或障碍（自动抠图）
- 结算可生成像素风成绩海报
